# 검증 도구 (db/tools/verify)

제출 전 전수 점검을 **다시 돌릴 수 있게** 남긴 스크립트. 매번 새로 만들지 않는다. 전부 **연습장(구
스택) 전용** — `DATABASE_URL`(애저)이 잡혀 있으면 계정·세션을 만드는 스크립트는 멈춘다. 애저 점검은
데모(연습장)에서 돌린다.

| 파일         | 하는 일                                                                                                                                        | AI 호출              | DB 쓰기                            |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------- | -------------------- | ---------------------------------- |
| `setup.ts`   | `[검증]` 계정 여섯(봉사·멘토봉사·종사자·겸직 종사자·센터장·종사자 폰) + 관리자(깃발 있는 사람, 없으면 센터장) 세션. 토큰은 `out/accounts.json` | 0                    | 계정(있으면 재사용)·세션           |
| `matrix.ts`  | 권한표 — 경로 126줄 × 신분 8 = **1,008회**. 기대값은 손으로 옮긴 등급(정책 코드를 읽지 않는다)                                                 | 0                    | 없음(없는 uuid·빈 본문)            |
| `anon.ts`    | 익명화 전수 — 실제 명단 + 비정형 이름 6명 × 표기·조사·문장 모양                                                                                | 0                    | 없음                               |
| `journey.ts` | 여정 완주 — 봉사자(초대코드→비번·동의→일정→일지→통계)·종사자(로그인→일지→분석→후보→가져오기→영역→초안→인쇄) 각 N회                             | 봉사 2·종사자 3 / 회 | `[검증]` 계정·일정·일지·관찰(남김) |
| `finish.ts`  | 검증 세션(`verify-script`)만 지운다                                                                                                            | 0                    | 세션 삭제                          |

## 순서

```bash
unset DATABASE_URL
deno run -A --env-file db/tools/verify/setup.ts
# 서버를 AUTH_ENFORCE=true 로 띄운 뒤
VERIFY_BASE=http://localhost:8000 deno run -A db/tools/verify/matrix.ts
deno run -A --env-file db/tools/verify/anon.ts
VERIFY_BASE=http://localhost:8000 deno run -A --env-file db/tools/verify/journey.ts 10
deno run -A --env-file db/tools/verify/finish.ts
```

단위 테스트는 `deno task test`(이 폴더 밖).

## 지키는 것

- `out/` 에는 세션 토큰이 들어 있다 — `.gitignore` 에 있다. 올리지 않는다.
- 비밀번호는 `journey.ts` 가 실행 때마다 만들어 API 로만 넣고 어디에도 적지 않는다(브라우저 칸에
  치지 않는다).
- 만든 `[검증]` 계정·일지·관찰은 **증거물로 남긴다**. 지우라는 지시가 있을 때만 id 로 지운다. 감사
  로그는 어떤 경우에도 지우지 않는다(원칙 12).
- 권한 등급을 바꾸면 `matrix.ts` 의 기대값도 **손으로** 고친다 — 코드에서 뽑으면 코드와 같이 틀린다.
