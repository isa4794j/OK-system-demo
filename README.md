# OK 시스템 데모

지역아동센터 통합 관리 시스템 **OK 시스템**의 공개 데모입니다. **가상 데이터로 운영**합니다 — 이
데모에 실제 아동·직원의 개인정보를 입력하지 마세요.

- 실행: **Deno Deploy**
- DB: **Supabase** (PostgreSQL)
- AI: Anthropic Claude API (익명화 게이트웨이 경유)
- 프론트: 순수 HTML/CSS/JS, PC 화면 + 봉사자·멘토 전용 휴대폰 화면(`/m`)

## 무엇을 하는가

- **일지**: 종사자 일지 3종(프로그램·일상·회의록)과 봉사일지.
- **AI 분석**: 저장된 일지에서 아동별 관찰과 사용 자원을 AI가 **후보로만** 뽑습니다. 확정은 사람이
  합니다.
- **관찰·평가**: 확정된 관찰은 영역별로 쌓이고, 반기마다 AI 초안을 바탕으로 사람이 연간평가를
  완성합니다.
- **자원·도서**: 활동 자원 사전과 통계, 도서 관리(바코드·표지 사진·제목 검색·엑셀 일괄 등록).
- **인쇄**: 관찰일지·평가서·개인정보 동의서.
- **권한·기록**: 관리자/센터장/종사자/봉사 4등급 접근 제어, 민감한 조작은 모두 감사 로그에 남습니다.

## 데모라서 다른 점

- 들어 있는 아동·직원·일지는 전부 **지어낸 데이터**입니다.
- 누구나 쓰는 화면이라 **매일 새벽 3시(한국 시각)에 처음 상태로 돌아갑니다.** 그때 쓰던 글도 함께
  사라지고, 로그인 창도 끊깁니다.
- 이 저장소는 데모 운영용입니다. 센터에서 실제로 쓰는 쪽은 별도 환경에서 운영합니다.

- 이 계정들의 비밀번호도 매일 초기화 때 위 값으로 돌아옵니다.

## 데모 운영 (관리자용)

- 초기화 작업: `.github/workflows/demo-reset.yml` — 매일 18:00 UTC(= 03:00 KST), 손으로도 돌릴 수
  있습니다 (Actions 탭 → 데모 초기화 → Run workflow).
- 되돌릴 기준 데이터는 DB 안 `demo_baseline` 스키마에 있습니다. 데모 데이터를 손본 뒤 기준을 다시
  잡으려면 `db/tools/demo/baseline.ts` 를 한 번 돌립니다.
- DB 접속 주소는 저장소 **Secrets 의 `DEMO_DATABASE_URL`** 하나뿐입니다. 코드·문서에는 적지
  않습니다.
- 표를 새로 만들면 `db/tools/demo/tables.ts` 에도 적어야 초기화 대상이 됩니다.

## 직접 돌려 보려면

1. `.env.example` 을 `.env` 로 복사하고 값을
   채웁니다(`SUPABASE_URL`·`SUPABASE_KEY`·`ANTHROPIC_API_KEY`·`AUTH_ENFORCE=true`).
2. `deno task dev` 로 띄우고 `http://localhost:8000` 을 엽니다.
3. 명단이 비어 있으면 첫 화면에서 **첫 종사자**를 직접 등록합니다(`docs/설치순서.md`).

```bash
deno task check   # 타입
deno task lint    # 린트
deno task test    # 단위 테스트
```

## 저장소 구조

- `main.ts` / `api/` — 라우팅·핸들러 (정책표 기반 접근 제어)
- `db/` — DB 접근 계층, `db/sql/` 마이그레이션 001~034, `db/tools/verify/` 전수 점검 재현 도구
- `lib/` — 익명화 게이트웨이(`ai.ts`), 도메인 로직
- `web/` — PC 화면, `web/m.html` + `web/assets/m/` 봉사자 휴대폰 화면
- `docs/` — 기능 지도, 설치 순서, 이용자·관리자 가이드, 개인정보 점검

## 설계 원칙

1. **익명화 게이트웨이** — AI로 나가는 모든 글은 `lib/ai.ts` 한 곳을 지나며 이름은 가명으로
   바뀝니다. 치환 뒤 유출 검사가 한 번 더 막고, 새면 전송 자체가 멈춥니다.
2. **추측 금지** — AI가 확신하지 못하면 "확인 필요"로 남기고 사람이 정합니다.
3. **접근 제어는 서버가 판단** — 정책표에 없는 경로는 기본 거부입니다.
4. **감사 로그는 지우지 않습니다.**
5. **사람이 확정** — 관찰·자원·평가 초안·책 인식 모두 사람 검토를 거쳐야 기록이 됩니다.
