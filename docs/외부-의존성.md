# 외부 의존성 (제출 문서 4.2)

2026-09-18 기준. `deno.json`·`deno.lock`·코드 전체를 조사해 확정했다. 라이선스는 npm·jsr 공식 메타데이터로 확인했다.

## 확인한 사항

- **ZXing** 은 자바스크립트 판 `@zxing/library` 로 MIT 다(원조 자바 ZXing 은 Apache-2.0 — 혼동 주의).
  CDN 이 아니라 우리 서버에서 나간다(`web/assets/vendor/`, 판 번호·sha256 은 그 폴더 README). [스캔] 을 누를 때만 불러오고,
  브라우저에 `BarcodeDetector` 가 있으면(안드로이드 크롬 등) 받지 않는다.
- **xlsx 파싱은 자체 구현**이다(`lib/xlsx.ts` — zip 목차·XML 을 직접 읽고, 압축 풀기는 내장 `DecompressionStream`). 외부 라이브러리 없음.
- 화면의 외부 `<script>` 태그는 0개. 실행 중에 받는 외부 자원은 PC 화면의 Google Fonts 글꼴뿐이다(로그인·휴대폰 화면은 기기 글꼴).
- 서버가 부르는 외부 API 는 셋: Anthropic, 국립중앙도서관(`nl.go.kr/seoji`), 도서관 정보나루(`data4library.kr`).
- Deno 표준 라이브러리: `@std/http`·`@std/path`, 테스트용 `@std/assert`(jsr, MIT). 딸린 `@std` 모듈 9개도 MIT.

## 참고

- **도서 표지 이미지**는 서지 API 가 준 주소를 브라우저가 직접 받는다(저장하지 않고 링크만). 2026-09-18 애저 도서 기준 알라딘(`image.aladin.co.kr`)·네이버(`bookthumb-phinf.pstatic.net`).
- **운영 인프라**(라이브러리 아님): Azure Container Apps · Azure Database for PostgreSQL · Azure Container Registry (Korea South).
- `deno.lock` 에 `@electric-sql/pglite` 계열 항목이 남아 있으나 앱 코드에서 쓰지 않는다(애저 이전 검증 실행에서 딸려 들어온 것). 의존성이 아니므로 표에 넣지 않았다. 잠금 파일은 그대로 둔다.
