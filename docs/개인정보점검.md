## 1. AI 로 나가는 것 (전송 지점 전수)

모든 AI 호출은 `lib/ai.ts` 한 곳을 지난다(모델 `claude-opus-5`, `lib/ai.ts:22`). 문은 셋이다.

| 문 | 가명화 | 운영에서 부르는 곳 |
|---|---|---|
| `callAISafe` (`lib/ai.ts:358`) | **강제** — `hide()` 로 이름을 토큰으로 바꾸고, `assertNoLeak()` 이 실명 흔적을 찾으면 **호출 전에 예외**. 답은 `show()` 로 실명 복원 | 관찰 추출 · 자원 추출 · 평가 초안 |
| `callAIWithImage` (`lib/ai.ts:198`) | **불가**(사진) — 형식 서명만 검사(`checkImageData`, `lib/ai.ts:169`) | 자원 사진 · 책 표지 |
| `callAI` (`lib/ai.ts:143`) | 없음 | **없음**(데모 `lib/ai_demo.ts` 만) |

가명화 대상 명단은 `lib/roster.ts:56` `listPeopleToMask()` — **아동 전원(종결 포함) + 직원·봉사자 전원**.

## 5. 보완 예정 목록 (이 점검에서 찾은 것 — 수정은 승인 뒤)

1. 감사 기록 실패 시 서버 로그에 값 통째 출력(`db/audit.ts:125`) — 값 대신 표·id·요약만 남기는 방안 검토.
2. 폰 스냅샷이 세션 만료 뒤에도 남음 — 401 때 비우기, 일정 시간 뒤 자동 삭제 검토.
3. 폰 봉사일지 작성 화면에 PC 와 같은 이름 표기 안내(`notice--privacy`)가 없음 — 폰은 서버 분석이 자동이라 안내가 더 필요.
4. 일지 통합 검색어(`?q=`)가 URL 에 실림 — POST 본문으로 옮기거나 호스팅 로그 정책 확인.
5. 가명화 명단 밖의 이름(보호자·형제·학교 사람)은 안내문에만 의존 — 탐지(예: "OO 어머니") 보강 검토.
6. ~~개인정보 수집·이용 **동의 기록 기능 없음**~~ → ③단계(2026-09-17): 종이 동의서 인쇄(Ⅴ AI 처리위탁·국외 이전 포함)·아동 동의서 받은 날·직원·봉사자 로그인 동의(034)·공개 처리방침 `/privacy`. 문구는 settings 편집형. **아동 동의 여부에 따른 AI 제외 로직은 없음**(기록만 — 동의하지 않은 아동은 사람이 수기로 관리).
7. 보존 기간·파기 정책(종결 아동 기록, 감사 로그) 없음.
8. 운영 `AUTH_ENFORCE`·anon 권한 회수(009) 적용 여부는 시스템 점검·008 진단으로 주기 확인.
