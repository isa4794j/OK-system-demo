# 감사보고서 요건 현황 (2차 자동 점검, 2026-09-17 — 조사만)

판정: **가능**(이미 화면·API 가 만든다) · **집계 없음**(데이터는 있으나 묶는 코드가 없다) · **데이터 없음**(저장 자체를 안 한다).
근거는 `파일:줄` / `테이블.칼럼`. 이 점검에서 코드는 고치지 않았다.

## 1. 아동 통계

| 항목 | 판정 | 근거 | 비고 |
|---|---|---|---|
| 연도별 재원 수 | 집계 없음 | `children_identity.status·enroll_date·exit_date` | 명단은 **오늘 기준** 재원·종결 인원만(`web/assets/children.js:244-247`). 입소일이 비어 있으면 연도 판단 불가 |
| 연도별 종결 수 | 집계 없음 | `children_identity.exit_date` | 종결일 없는 옛 종결은 연도 불명 |
| 학년 분포 | 집계 없음 | `birth_date` → `lib/roster.ts:25 gradeNumber`(기준일 인자 있음) | 명단 표의 칸으로만 보임 |
| 성별 분포 | 집계 없음 | `children_identity.gender` | 명단 표의 칸으로만 보임 |

`GET /api/children` 이 위 칸을 모두 주므로 화면에서만 세어도 만들 수 있다.

## 2. 일지 건수

| 항목 | 판정 | 근거 | 비고 |
|---|---|---|---|
| 종류별 기간 건수 | 부분 가능 | `GET /api/journals?kind&from&to` → `total`(최대 366일) · 목록 머리 "N건" | 한 번에 한 종류. 1/1~12/31 을 골라 종류마다 읽어야 함 |
| 월별 12개월 표 | 집계 없음 | `journals.kind·journal_date` | 달마다 따로 조회만 가능 |
| 봉사일지 역할별 | 부분 가능 | `role=멘토/봉사자` 거르기 | 검색어 "봉사자"·"멘토" 가 역할로 바뀜 |
| 종사자 일지 역할별 | 집계 없음 | `journals.as_role` | 종사자 일지 화면엔 역할 거르기 없음 |
| 봉사일지 작성 수(월·사람·역할) | 가능(월) | `GET /api/schedules?year&month` → `stats` · PC 스케줄 근무 통계 | 일정에 매인 일지 기준 |
| 봉사일지 작성 수(본인 연간) | 가능(본인만) | `GET /api/my/stats` → 폰 [나] | 올해 고정 |

## 3. 프로그램별 실시 횟수 · 참여 아동

| 항목 | 판정 | 근거 | 비고 |
|---|---|---|---|
| 프로그램명(정해진 값) | 데이터 없음 | `journals.title`(자유 글)·`content` 만 | 프로그램 사전·id 없음 |
| 프로그램별 실시 횟수 | 집계 없음(조건부) | `journals.kind='프로그램'` + `title` | 제목 표기가 통일돼 있을 때만 셀 수 있음 |
| 참여 아동 명단 | 데이터 없음 | 참여자 칸·표 없음 | 본문 속 이름은 따로 저장되지 않음 |
| 참여 아동 근사치 | 집계 없음(한계 큼) | `journal_observations.journal_id·child_id`, `observations.source_journal_id` | AI 가 **관찰이 적힌 아동만** 뽑음 — "관찰 기록된 아동 수" 이상으로 쓰기 어려움 |

| 자원 활용(카테고리·자원별, 월·반기·연간) | 가능 | `GET /api/resource-stats` · 자원통계 화면 | 통계 기록(status Y)만 |

## 5. 봉사 연인원 · 총시간

| 항목 | 판정 | 근거 | 비고 |
|---|---|---|---|
| 월별 총시간·일정 수·역할별 인원 | 가능(월) | `GET /api/schedules?year&month` → `stats.totals`·`by_role` · PC 근무 통계 | 사람×역할 기준(겸직은 역할마다) |
| 센터 전체 **연간** 총시간·연인원 | 집계 없음 | `schedules.staff_id·sched_date·start/end·as_role` | month 필수 — 12번 조회 합산 필요, 실인원은 staff_id 로 따로 세야 함 |
| 개인별 연간 합계 | 가능(본인만) | `staffYearStats` → `/api/my/stats` | 관리자가 남의 연간 합계를 보는 길 없음 |
| 시간 산정 기준 | 참고 | 일정 시작~종료 차이 | **계획 일정** 기준(앞날 일정 포함) |

## 6. 출력 경로

| 항목 | 판정 | 근거 |
|---|---|---|
| 인쇄용 CSS / 인쇄 버튼 | **③단계에 생김** | `/print` — 관찰일지·평가서(아동별)·동의서(빈 양식), `window.print`. 통계 표 인쇄는 아직 없음 |
| CSV·엑셀 **내보내기** | 없음 | `lib/xlsx.ts` 는 읽기 전용(도서 엑셀 등록) |
| PDF | 브라우저 "PDF로 저장" | 라이브러리 없음 |
| 파일 내려받기 | 없음 | `createObjectURL` 은 사진 미리보기에만 |
| 복사 | 한 곳 | 감사 로그 한 건 JSON 복사(보고서용 아님) |

요약: 원자료는 대부분 있다. 연간 집계가 이미 나오는 것은 **자원 활용 통계(연간)** 와 **봉사자 본인 연간 합계** 둘뿐이고, **출력 경로는 아동 기록 인쇄(③단계)뿐 — 통계 출력은 없다.**
