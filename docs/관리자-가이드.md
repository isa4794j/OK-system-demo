# 관리자 가이드 — 종사자·센터장·관리자 (컴퓨터)

센터 컴퓨터(넓은 화면)에서 쓰는 화면입니다. 왼쪽에 큰 탭 셋이 있습니다.

| 탭 | 안에 있는 것 |
| --- | --- |
| 👥 **아동** | 아동 / 종사자 / 멘토+봉사자 |
| 📦 **자원** | 자원사전 / 자원통계 / 도서관 |
| ⚙️ **설정** | 문의함 / 동의서 / 계정 관리 / 봉사자 설정 / 관찰 영역 / 변경 기록 / 관문 경고 / 시스템 점검 |

보이는 항목은 등급에 따라 다릅니다. 종사자는 설정에서 문의함·동의서만 보입니다.

---

## 1. 일지 쓰기 (4종)

일지는 **프로그램 · 일상 · 회의록 · 봉사** 네 가지입니다. 앞의 셋은 종사자가 쓰고, 봉사일지는 봉사자·멘토가 휴대폰으로 씁니다.

1. [아동] 탭 → **[종사자]** → **[프로그램]**(또는 일상·회의록) 을 고릅니다.
2. 오른쪽 위 **[+ 일지 작성]** 을 누릅니다.
3. **날짜 · 작성자 · 제목 · 내용** 을 적습니다.
   - 작성자는 기본이 본인입니다. 다른 선생님 대신 쓸 때만 바꿉니다.
4. **[저장]** 을 누릅니다.

- 달 이동은 머리줄의 `‹ 2026년 9월 ›` 로, 특정 날짜·기간은 옆의 📅 로 고릅니다.
- 검색창에 작성자 이름이나 본문 낱말을 넣으면 그 달 안에서 찾습니다.
- 일지 카드 아래에 `관찰 6 · 자원 0` 처럼, 그 일지에서 뽑힌 후보 수가 보입니다.
- 저장하면 AI가 관찰·자원 후보를 뽑습니다. 오래된 일지가 "미분석" 으로 남아 있으면 머리줄의 **[미분석 일괄 분석 N]** 으로 한 번에 돌립니다(돌 때는 "분석 중… 3/12", 남은 것이 없으면 [모두 분석됨] 으로 꺼져 있습니다).

## 2. AI 후보 검토 — 관찰 가져오기

AI는 **후보만** 만듭니다. 아동에게 넣는 것은 사람이 정합니다.

1. [아동] 탭 → 명단에서 아동 이름을 누릅니다.
2. **[날짜별 · 편집 →]** 를 누릅니다. 옆의 숫자가 가져오지 않은 후보 수입니다.
3. **[일지에서 관찰 가져오기]** 를 누릅니다.
4. 목록에서 이 아동의 관찰로 넣을 것만 고릅니다. **[전체 선택]** 으로 한 번에 고를 수도 있습니다.
   - 이미 가져온 것, 다른 관찰에 합쳐진 것은 흐리게 잠겨 있고 고를 수 없습니다.
5. **[선택한 관찰 가져오기]** 를 누릅니다.

- 가져온 관찰은 **영역이 미지정** 상태로 들어갑니다. 영역은 다음 단계에서 고릅니다.
- 창을 열 때 선택은 항상 비어 있고 버튼은 [전체 선택] 로 시작합니다.

### 영역 지정

1. 같은 편집 화면의 날짜별 관찰에서 각 줄의 **영역 단추**를 누릅니다.
2. 건강상의 유의점 / 학습 / 또래관계 / 행동이나 정서상의 변화 / 보호자나 아동의 특별한 요구사항 / 연계 중에서 고릅니다.
3. **[미지정만 보기]** 를 켜면 아직 영역을 안 고른 것만 보입니다.

- 한 줄을 고치거나 둘로 나눌 때는 그 줄의 **[수정]·[나누기]·[삭제]** 를 씁니다.
- 일지에서 온 것이 아닌 관찰은 **[+ 관찰 직접 추가]** 로 넣습니다.

## 3. 아동 상세 — 평가와 근거

아동 이름을 누르면 카드가 차례로 나옵니다: 아동 정보 / 영역별 관찰 / 성장 추이 / 연간 평가 / 날짜별 관찰.

- **아동 정보**: ▸ 를 누르면 펼쳐집니다. [수정]·[삭제] 가 있습니다. 그만둔 아동은 삭제 대신 상태를 '종결' 로 바꿉니다.
- **영역별 관찰**: 영역마다 몇 건인지 보이고, [전체 펼치기] 로 한 번에 펼칩니다. **[🖨 인쇄]** 로 관찰일지를 종이로 뽑습니다.
- **연간 평가**:
  1. 머리줄의 ▸ 를 눌러 펼칩니다. 상반기·하반기는 위의 칩으로 고릅니다.
  2. **[수정]** 을 누릅니다.
  3. **[AI 초안 생성]** 을 누르면 그 반기의 관찰을 근거로 영역별 초안이 채워집니다. **초안은 저장되지 않습니다** — 읽고 고친 뒤 **[저장]** 을 눌러야 남습니다.
  4. 평가지가 필요하면 **[🖨 인쇄]** 를 누릅니다.

### "근거 바뀜" 알림

- 평가를 저장한 뒤 근거가 된 관찰이 바뀌면(고쳐짐·지워짐·새로 들어옴) 연간 평가 머리줄에 **근거 바뀜** 배지가 뜹니다. 접혀 있어도 보입니다.
- 펼치면 무엇이 바뀌었는지 나옵니다. 읽고 받아들였으면 **[근거 확인함]** 을 누릅니다. 평가 본문은 바뀌지 않고, "근거 확인함 · 9월 18일 · 이름" 만 남습니다.
- 내용을 고쳐야 하면 [수정] 에서 고쳐 저장합니다.

## 4. 자원·도서 등록

### 자원 (자원사전)

1. [자원] 탭 → **[자원사전]**.
2. **[+ 자원 등록]** 을 누르고 이름을 적습니다. 별칭도 함께 적어 두면 일지에서 다르게 불러도 같은 자원으로 잡힙니다. **[저장]**.
3. 창은 저장 뒤에도 열려 있습니다. 이어서 다음 자원을 넣고, 끝나면 [닫기] 를 누릅니다.

- 같은 창 아래 "사진으로 여러 개 한꺼번에" 에서 **[📷 찍기]·[🖼 갤러리]** 로 사진을 넣으면 한 장에서 여러 자원을 읽습니다(10~20초). 읽은 것 중 등록할 것만 고릅니다.
- 일지에서 AI가 새 자원을 찾으면 자동으로 등록되고 "자동 등록" 표시가 붙습니다. 카테고리가 비면 **미분류함**에 모입니다 — 거기서 채웁니다.
- 카테고리 이름·순서는 [카테고리 관리] 에서 바꿉니다.

### 도서 (도서관)

1. [자원] 탭 → **[도서관]** → **[+ 도서 등록]**.
2. 넣는 방법은 넷입니다.
   - **ISBN** 을 적고 **[ISBN 조회]** — 제목·저자·출판사·발행년·분류가 채워집니다.
   - **[스캔(바코드)]** — 카메라로 책 뒤 바코드를 찍습니다.
   - **제목**을 적고 **[찾기]** — 검색 결과에서 고릅니다.
   - **[📷 표지 사진]** — 표지나 책등 사진에서 여러 권을 한 번에 읽습니다.
3. 등록번호·센터분류·상태·입수경위·비고는 센터에서 쓰는 값입니다(선택).
4. **[저장]**.

- **[📄 엑셀로 등록]** 으로 목록 파일을 올릴 수 있습니다. 열 이름이 달라도 내용을 보고 제목·저자·출판사·ISBN·등록번호를 짐작하며, 올린 뒤 사람이 확인합니다. 한 번에 100줄까지.
- 조회로 채운 책은 서지가 잠깁니다. 서지가 비었거나 분류가 없는 책에는 **[ISBN 다시 검색]** 이 보입니다.
- 파일과 사진은 읽는 데만 쓰고 어디에도 저장하지 않습니다.

### 자원통계

[자원] → [자원통계] 에서 그 달의 쓰임을 봅니다. 카테고리별은 펼쳐진 채로 시작하고, 자원별·오래 안 쓴 자원은 ▸ 로 펼칩니다. "오래 안 쓴 자원" 은 60일 넘게 기록에 안 나온 것입니다 — 판단은 선생님 몫입니다.

## 5. 인쇄 (3종)

인쇄는 넓은 화면에서만 보입니다. 브라우저 인쇄창이 열리고, A4 한 장 기준으로 맞춰져 있습니다.

| 무엇 | 어디서 |
| --- | --- |
| 관찰일지 | 아동 상세 → 영역별 관찰의 **[🖨 인쇄]** |
| 연간 평가서 | 아동 상세 → 연간 평가의 **[🖨 인쇄]** |
| 개인정보 동의서 | [설정] → [동의서] → **[동의서 인쇄]** |

## 6. 계정 관리 (센터장 이상)

1. [설정] → **[계정 관리]**. 머리줄에 `활성 N · 대기 N · 미발급 N` 이 보입니다.
2. 새 사람은 먼저 명단에 등록합니다([아동] 탭 → 종사자 또는 멘토+봉사자 → [+ 등록]).
3. 그 사람 줄의 **[코드 발급]** 을 누릅니다. 6자리 코드가 큰 글씨로 한 번만 보입니다.
4. **[📋 안내 글 복사]** 를 누르면 아래 세 줄이 복사됩니다. 문자·메신저로 보내면 됩니다.
   - OK 시스템 로그인 초대코드입니다.
   - 이름(아이디): ○○○ / 초대코드: 123-456
   - 접속 주소: (지금 쓰는 주소)에서 초대코드로 첫 비밀번호를 설정해 주세요.
5. 창을 닫은 뒤에도 그 줄의 **[복사]** 로 같은 글을 다시 복사할 수 있습니다(화면을 새로 고치기 전까지).

- 코드는 **30일**까지 유효합니다. 서버는 코드를 해시로만 저장해 다시 보여 줄 수 없습니다 — 놓치면 [코드 재발급].
- 비밀번호를 잊은 사람은 **[비번 재설정]** 으로 새 코드를 줍니다.
- 줄 끝 **[⋯]** 에 나머지가 있습니다: 발급한 코드 회수 / 로그인 이름 고치기 / 접속 권한을 PC↔모바일로 / 관리자로 지정·빼기 / 계정 정지·해제.
- **관리자는 둘 이상**을 권합니다. 마지막 한 명은 서버가 해제·정지를 거절합니다.

### 역할과 겸직

- 사람마다 역할을 여러 개 줄 수 있습니다(예: 멘토+봉사자). 등급은 가장 높은 역할을 따릅니다.
- 겸직인 사람은 휴대폰 머리줄에서 지금 역할을 바꿀 수 있고, 일정·일지에는 그때의 역할이 기록됩니다.
- 접속 권한이 '모바일' 인 계정은 휴대폰 화면만 씁니다. 종사자는 'PC' 입니다.

## 7. 설정

### 동의서 (종사자도 볼 수 있음)

- [설정] → **[동의서]**: 아동·보호자용 개인정보 동의서와 로그인 화면에 걸리는 처리방침을 봅니다.
- **[문구 수정]**(센터장 이상)에서 센터 이름·문구를 고칩니다. 고친 기록은 변경 기록에 남습니다.
- 보관처·업체 이름이 들어간 문장은 코드가 아니라 이 문구에 있습니다. 서버를 옮기면 여기서 고칩니다.

### 시스템 점검 읽는 법 (관리자)

[설정] → **[시스템 점검]** → **[점검 실행]**. 일곱 가지를 봅니다.

| 항목 | 정상일 때 |
| --- | --- |
| 환경변수 | 필요한 키와 잠금 설정이 모두 있음 |
| DB 연결 | 연결됨 |
| 고아 데이터 | 서로 어긋난 기록 0 |
| 정책표 커버리지 | 경로·권한 짝이 맞음 |
| 감사 로그 | 기록이 쌓이고 있음 |
| 계정 | 로그인할 수 있는 관리자 2명 이상 |
| 더미 표식 | 검증 흔적 0 |

- **문제(빨강)** 는 바로 손봐야 합니다. **주의(노랑)** 는 읽고 판단하는 것입니다.
- 자주 보는 주의 두 가지: "누가 했는지 비어 있는 기록" (로그인 붙이기 전 기록이면 정상), "평가 스냅샷이 가리키는데 지금 없는 관찰" (관찰을 지운 뒤 평가에서 [근거 확인함] 을 누르면 사라집니다).

### 그 밖

- **문의함**: 봉사자가 휴대폰에서 보낸 문의를 읽고 확인 표시를 남깁니다.
- **봉사자 설정**(센터장 이상): 봉사자끼리 서로의 일지를 볼 수 있는지 정합니다.
- **관찰 영역**(관리자): 영역 이름을 고칩니다. 코드는 바뀌지 않아 지난 기록이 흐트러지지 않습니다.
- **변경 기록**(관리자): 누가 언제 무엇을 지우고 고쳤는지 값째 남습니다.

## 8. 운영 규칙

- **이름은 명단에 등록된 표기 그대로 적습니다.** 기록을 AI로 분석할 때 등록된 이름만 【아동1】 같은 표시로 바꿔 보내기 때문입니다. 명단에 없는 별명으로만 적으면 그 표기는 가려지지 않습니다.
  - 성을 뗀 이름("민수", "마이")과 띄어쓰기가 다른 표기는 가려집니다.
  - 별명을 꼭 써야 하면 그 별명으로 명단에 등록하거나, 일지에 등록 이름을 함께 적습니다.
- **아동 사진은 올리지 않습니다.** 사진은 자원·책 등록에만 씁니다. 글과 달리 사진은 가릴 수 없습니다.
- **AI는 초안·후보만 만듭니다.** 관찰을 아동에게 넣는 것, 영역을 정하는 것, 평가를 저장하는 것은 모두 사람이 합니다.
- **지우기 전에 확인창을 읽습니다.** 딸린 기록 수가 함께 나오고, 기록이 있으면 이름을 적어야 지워집니다. 아동·직원은 삭제 대신 '종결'·'종료' 를 권합니다.
- 계정은 한 사람에 하나입니다. 센터 컴퓨터를 함께 쓰더라도 화면 위의 이름을 확인하고 씁니다.
